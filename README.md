> Alarm at 6 AM on Saturday: congrats, you are not punctual, you are just a tiny terrorist with a snooze button.

## How it works
`main.py` holds the entry line as a constant, validates it against the 1-200 character gate (single line, non-blank), and writes it as UTF-8 bytes with no trailing newline to `/output/entry.txt`.

## Run
```bash
python3 main.py
```
